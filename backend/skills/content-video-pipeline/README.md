# 跨领域内容视频流水线 Skill

这是一个可移植的 Codex Skill，帮助个人创作者把不同领域的主题与素材组织成包含脚本、旁白、画面、字幕、动效和成片检查的视频流程。AI 负责协助执行，创作者负责目标、判断、表达和最终审核。

## 安装

将 `content-video-pipeline` 文件夹复制到 Codex 用户技能目录，例如：

```text
~/.agents/skills/content-video-pipeline/
```

开始新的 Codex 会话后，可通过描述匹配视频制作流程相关请求。

## 使用前按自己的环境适配

这份 Skill 不包含平台密钥、私有服务地址、个人声线 ID，也不会自动安装工具或获得账号权限。请结合自己的项目说明补充或确认：

1. 内容主题、受众、平台、时长和领域特定的准确性要求。
2. 输入资料的来源，以及 MCP、RSS、API、数据库或人工整理等入口。
3. 旁白、录音和音频处理方式，以及可使用的声线。
4. 视频编辑/渲染工具、检查方式、品牌素材和固定归档目录。

输入可以是新闻、课程、采访、研究、个人经验或用户提供的材料。把不同来源整理成适合主题的场景脚本后，后续的声音、画面与检查环节就能形成自己的流水线。

不要把 API Key、Cookie、个人 voice ID、私有连接地址或未公开素材写进公开 Skill。涉及专业或高风险领域时，采用相应核验与审阅标准。
