# 联通集团 PPT 版式规则

依据保留的原生集团模板和用户提供的示例稿提取。它是该批材料的设计归纳，不等同于完整的官方品牌规范。

## 画布与色彩

- 16:9，原文件 12,192,000 × 6,858,000 EMU，等价于 1280 × 720 CSS px、33.87 × 19.05 cm。
- 白底为主，黑色标题，品牌红作关键强调。Logo 原始素材主红约 `#E60027`；旧生成脚本使用 `#E20128`。单份文件保持一致，不需要重绘 Logo 改色。
- 正文 `#161616`，辅助文字 `#666666`，来源 `#707070`；目录次要条目 `#858585`。灰色仅承担次级层次。
- 不引入通用科技蓝、渐变背景、圆角卡片和大面积阴影。除非用户明确调整设计。

## 固定元素

- 封面 Logo 右上，约 x=850、y=55、w=360、h=106；左侧红色竖线约 x=155、y=294、w=5、h=320。
- 封面主标题约 x=214、y=306，40pt 左右；副标题和日期约 18–20pt。标题长时换为两行并整体检查，不挤压 Logo。
- 正文页标题约 x=32、y=32，24pt 加粗；Logo 约 x=1088、y=10、w=165、h=49。
- 正文页通栏红线 y≈86、h≈3，属于源模板固定页眉分隔元素。
- 内容区推荐 x=60–1220、y=135–630；来源区 y≈668，页码右下。页眉本来贴近画布边缘，不按新设计默认边距改动。
- Logo 宽高比约 3.398，不拉伸、不拆开重画、不重复叠加。若使用带 Logo 的母版，不再额外加一个 Logo。

## 字号（PPT 点）

| 用途 | 建议 |
|---|---|
| 封面 | 40pt 左右，加粗 |
| 页标题 | 24pt，加粗 |
| 内容主结论 | 28–33pt |
| 大数字 | 39–60pt，红色 |
| 正文 | 17–22pt |
| 说明 | 13–17pt |
| 来源/页码 | 10–12pt |

生成器采用 CSS px，字号乘 4/3 后传入，不能把 pt 直接作为 px。

## 页型选择

- 封面：Logo、竖线、主标题、副标题、日期，大量留白。
- 目录：三至五个条目，编号与文字分别在矩形条中，首条红、其余灰、白字。条目超过五项时合并章节或增加一页，避免压缩。
- 章节：沿用页眉，可在中下部用大号章节名，留白；不要只剩一个页眉标题却作为有信息量的正文。
- 概况：左侧结论与关键数字，右侧相关官方实景图。照片保留主体、标注场景与来源，不用无关机房图冒充真实客户案例。
- 数据：少量红色大数字搭配原生图表，标单位、年份和统计主体；柱形图默认零起点，避免夸大差异。
- 业务：二栏对照、四栏关键词、原生表格或编号说明行，白底平铺，避免所有内容都包进盒子。
- 结束：右上 Logo，中央黑色大字“守正创新 行稳致远”或用户指定结语。

内容多时拆页，先精简文案，再调布局，不优先缩小字体。图表、表格和正文都应可编辑；品牌素材保留原始图片。
