# 产物工作区与部门协作

数字员工生成的文件会登记到产物工作区。用户可在工作区搜索个人产物、打开来源会话，也可把单个产物共享给当前部门。

## 当前能力

- 产物工作区汇总当前用户创建的可用文件，支持按文件名、员工和会话标题搜索。
- 部门共享采用显式授权。创建者可共享或撤销单个文件；同部门成员只能查看和下载该文件。
- 部门成员不会因此获得来源会话的访问权。共享产物列表不会返回来源会话 ID、标题或数字员工信息。
- 本租户平台管理员可查看和下载所有已登记产物，并保留 workspace 范围内的旧接口运维访问。
- 新登记的产物会立即复制到隐藏的用户/会话存储区，避免根目录文件被其他用户会话覆盖，或个人目录文件被同一用户的其他会话覆盖。升级前已登记的文件会在首次下载或共享时迁移；若同路径文件此前已被覆盖，只能保存迁移时磁盘上的版本。
- 下载和预览优先使用产物 ID，经当前用户、租户和部门权限校验。旧的 path 下载入口保留迁移前路径映射；为兼容旧版单企业共享工作区，未登记的根目录文件仍可被登录用户访问，普通用户不能访问他人 UID 目录，管理员可在 workspace 范围内运维访问。新产物应通过登记后的产物 ID 和 ACL 访问。
- 共享和撤销共享操作进入管理审计日志。

## 使用方式

1. 在对话中让数字员工生成报告、看板、表格或文档。
2. 打开侧栏「产物工作区」，搜索并预览或下载生成的文件。
3. 为账号配置部门后，创建者可点「共享到本部门」。撤销后，其他部门成员将无法再通过产物工作区访问该文件。

只共享文件本身，不会共享完整会话。若需要同事共同修改会话、评论、版本历史或审批发布，当前版本尚不支持。

## 数据与部署说明

产物元数据、会话索引和部门共享记录保存在 `conversations` 数据库；实际文件保存在 `workspace/data/` 卷中。隐藏目录 `.artifact-store/` 保存按用户和会话隔离的产物副本。部署时必须一并备份 `workspace` 卷；仅备份 PostgreSQL 不包含文件内容。

当前工作区是单企业、单部门共享范围的第一期能力。尚无对象存储、保留期/回收站、文件版本、外链过期、跨部门授权、协同编辑和恢复演练。生产部署仍需为 `workspace` 卷设置访问控制、备份策略和容量监控。
